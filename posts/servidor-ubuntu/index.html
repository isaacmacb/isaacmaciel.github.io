Como Transformei um Notebook Antigo em um Servidor Ubuntu

📅 6 de julho de 2026 🐧 Linux ⏱️ 5 min de leitura

🔍 Introdução

Reaproveitar hardware antigo é uma prática sustentável que também pode ser extremamente educativa e econômica. Neste artigo, compartilho como transformei um notebook antigo em um servidor Ubuntu Server, criando um ambiente de estudos e hospedagem para projetos pessoais.

Esta experiência demonstra como é possível construir uma infraestrutura de baixo custo para aprendizado e desenvolvimento de projetos reais.

💻 Hardware Utilizado

  • Notebook: Modelo antigo com processador Intel Core i3 de 2ª geração
  • Armazenamento: SSD de 120GB (upgrade essencial para performance)
  • Memória: 8GB RAM (expandida para melhor desempenho)
  • Rede: Conexão cabeada para estabilidade
  • Alimentação: Fonte original com no-break

Mesmo sendo um equipamento modesto, foi perfeitamente suficiente para executar diversos serviços e aplicações.

📥 Instalação do Ubuntu Server

O processo de instalação foi realizado nas seguintes etapas:

  • Download da ISO: Baixei a versão LTS do Ubuntu Server (24.04)
  • Pendrive Bootável: Criei com Rufus, garantindo compatibilidade com o hardware antigo
  • Instalação Minimal: Optei pela instalação minimal, mantendo apenas o essencial para um servidor
  • Configuração de Rede: IP fixo para facilitar o acesso remoto
  • SSH: Habilitado para administração remota

🔧 Serviços Instalados

Após a instalação base, configurei diversos serviços:

  • Docker: Para containerização de aplicações
  • Portainer: Interface gráfica para gerenciamento de containers
  • Nginx: Servidor web e proxy reverso
  • PostgreSQL: Banco de dados relacional
  • Node.js: Ambiente para aplicações JavaScript
  • Uptime Kuma: Monitoramento de serviços

🛡️ Segurança e Manutenção

Algumas práticas importantes que adotei:

  • Firewall: Configuração do UFW (Uncomplicated Firewall)
  • SSH Key: Acesso seguro sem senha
  • Fail2ban: Proteção contra ataques de força bruta
  • Atualizações: Script automático para atualizações de segurança
  • Backup: Rotinas diárias de backup para o Dropbox

📌 Aprendizados e Benefícios

  • ✅ Reaproveitamento de hardware que seria descartado
  • ✅ Ambiente de aprendizado prático em Linux
  • ✅ Hospedagem de projetos pessoais e portfólio
  • ✅ Experiência em administração de servidores
  • ✅ Custo zero para hospedagem
  • ✅ Controle total do ambiente

🧠 Tecnologias

Ubuntu Linux SSH Docker Nginx PostgreSQL Portainer

🏁 Conclusão

Transformar um notebook antigo em servidor foi uma das experiências mais enriquecedoras da minha jornada como desenvolvedor. Demonstra que com conhecimento técnico e criatividade, é possível construir soluções úteis com recursos limitados.

Este projeto me proporcionou um laboratório de aprendizado que continua sendo uma ferramenta valiosa para testes e desenvolvimento de novas habilidades.
